# STM32 Deep Dive

ARM Cortex-M과 STM32를 HAL 없이 레지스터 수준에서 바닥부터 공부

## 타겟 보드

| 항목 | 내용 |
|---|---|
| 보드 | STM32F746G-DISCO |
| MCU | STM32F746NG |
| 코어 | ARM Cortex-M7, 최대 216MHz, I/D 캐시 |
| 내부 메모리 | Flash 1MB, SRAM 320KB |
| 외부 메모리 | SDRAM(FMC), QSPI Flash |
| 디버거 | 보드 내장 ST-LINK |

## 목표

**최종 목표**
- ARM Cortex-M과 STM32를 "써 본 사람"이 아니라 "설명할 수 있는 사람"이 되기
- 이 학습을 바탕으로 나만의 임베디드 베이스 코드 만들기

**2026년 목표**
- 전원 인가부터 main()까지, 빌드와 부팅 과정을 HAL 없이 직접 구현하기

## 학습 규칙

- CMSIS 헤더까지만 사용 (HAL, LL, CubeMX 생성 코드 사용 안 함)
- 각 항목은 **읽기 → 실험(일부러 망가뜨리기 포함) → 노트** 순서로 진행
- 완료 기준: 백지에 설명 가능 + 실험 코드 커밋 + 노트 작성
- 회사 코드, 데이터, 사내 자료는 넣지 않음

## 개발 환경

- 툴체인: arm-none-eabi-gcc, Make
- 디버깅: OpenOCD, gdb
